# NaveChan

### 🇧🇷 Português (Brasil)

NaveChan é um fórum anônimo criado como um espaço para conversas, interações e compartilhamento de ideias. Inspirado em imageboards, o projeto permite que usuários publiquem mensagens anonimamente e interajam por meio de respostas em tópicos.

O sistema conta com um mural de postagens recentes, respostas organizadas por publicação e atualização em tempo real, proporcionando uma experiência simples e dinâmica.

Desenvolvido com **HTML, CSS, JavaScript e Supabase**. É um projeto independente e não possui vínculo oficial com o CEJLL – NAVE.

**Acesse:** https://navechan.netlify.app/

---

### 🇺🇸 English

NaveChan is an anonymous forum designed as a space for conversations, interactions and sharing ideas. Inspired by imageboards, the project allows users to publish messages anonymously and interact through threaded replies.

The platform features a recent posts board, organized replies and real-time updates, providing a simple and dynamic experience.

Built with **HTML, CSS, JavaScript and Supabase**. This is an independent project and is not officially affiliated with CEJLL – NAVE.

**Visit:** https://navechan.netlify.app/
